    <summary><b>⚙️ How it works</b></summary>
    <br />
    <div align="center">
      A small interactive game that runs directly inside the GitHub profile README.<br />
      The game is controlled through image links. Each button sends an action to the game server, which updates the
      game state and returns the current game image.<br />
      <code>GitHub README</code> → <code>Click button</code> → <code>/action?move=...</code> →
      <code>Game state updated</code> → <code>Game image generated</code> → <code>GitHub loads image</code><br />
      The game works without JavaScript or any client-side application running inside GitHub.<br /><br />
